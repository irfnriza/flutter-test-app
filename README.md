# flutter_test_app

Project Flutter sederhana untuk memastikan instalasi dan build berjalan.

## Menjalankan

1) Pastikan device/emulator aktif.
2) Jalankan:
	 flutter run

## Catatan

- Jika build pertama terasa lama, itu normal karena Gradle dan SDK perlu diunduh.
- Jika ada error SDK, jalankan:
	flutter doctor -v
